# Task 44 — UI Mockup

`UI_MOCKUP.html` is a static, disabled mockup. It labels the view as a claim-verification demonstration, displays the three allowed outcomes, shows an explicit `INSUFFICIENT_EVIDENCE` state, marks all evidence as synthetic, and states that it is not an authoritative fact-check.

It is not mounted by `app.py`, does not call an API, and does not display real citations.
